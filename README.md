# Physics Calculator

A dark-themed educational physics calculator built with plain HTML, CSS, and JavaScript.

## Features

- Motion calculations
- Force calculations
- Work and energy calculations
- Momentum calculation
- Electricity calculations
- Step-by-step solutions
- Unit selectors and automatic conversion to standard units
- Distance, time, mass, velocity, force, energy, power, voltage, current, and resistance units
- Formula reference
- Input validation
- Responsive layout
- No frameworks or external dependencies

## Files

- `index.html` — Website structure
- `style.css` — Website design
- `script.js` — Calculator logic

Calculations convert input values to standard units automatically. The solution shows both each original value and its converted standard-unit value.

## Current Formulas

### Motion
- Speed: v = d / t
- Velocity: v = Δx / t
- Acceleration: a = (v₂ − v₁) / t

### Force
- Force: F = ma
- Mass: m = F / a
- Acceleration: a = F / m

### Work & Energy
- Work: W = Fd
- Kinetic Energy: KE = ½mv²
- Power: P = W / t

### Momentum
- Momentum: p = mv

### Electricity
- Voltage: V = IR
- Current: I = V / R
- Resistance: R = V / I
- Electrical Power: P = VI
